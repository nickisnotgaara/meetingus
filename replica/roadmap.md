# Оставшиеся задачи (roadmap)

Приоритеты: P0 — блокеры качества и первые пользовательские сценарии,
P1 — функциональность, обещанная рекогносцинацией, P2 — волна 2.
Критерий готовности указан для каждой задачи; статус текущего дня —
в `replica/status.md`.

## P0 — качество и «основные функции»

- [ ] **Разобраться с жалобой «основные функции не работают»** — получить
  сценарий воспроизведения (кнопка/поток, сборка, скриншот), воспроизвести,
  починить, покрыть прогоном. Критерий: жалоба закрыта, повторный прогон
  `ui-e2e.js` 16/16.
- [ ] **UI-визард онбординга (D13)** — три шага: микроверька уровня (события
  `mic://level` уже есть), ввод MiMo-ключа (`set_api_key` готов), выбор и
  скачивание модели с прогрессом (`model_catalog`/`model_download`/`model_activate`
  готовы). Критерий: свежая установка доводится до рабочего состояния без
  ручного вмешательства; повторный проход невозможен (`onboarded=1`).
- [ ] **Привести UI в соответствие с референсом Cluely** — после жалобы на
  «сомнительный» вид: сверка по `replica/design/tokens.json` и скриншотам,
  состояния пустого экрана, длинных ответов, ошибок, ширины/отступов.
  Критерий: визуальная сверка по каждому экрану из `replica/recon.md`.
- [ ] **Проверка в реальном звонке** (Zoom/Meet/Teams): loopback ловит «them»,
  микрофон — «me», эхо дедуплицируется, ничего не падает при ducking.
  Критерий: чек-лист по features.csv S01–S05 пройден вживую.

## P1 — функциональность из рекогносциции

- [ ] **Прошлые встречи (D15)** — список сессий + поиск по transcript через
  FTS5 (`db::search_chunks` готов), просмотр чата/ответов по сохранённой
  встрече. Критерий: поиск находит встречу по фразе из транскрипта.
- [ ] **Modes и настройки** — таблицы `modes`, `files`, `settings` уже в
  схеме: CRUD режимов (инструкции + email-шаблон), загрузка файлов
  контекста, выбор языка/модели/горячих клавиш. Критерий: режим переключает
  поведение Assist и сохраняется между запусками.
- [ ] **Авто-детект встречи (D14)** — энергия loopback + заголовок процесса
  конференции → автостарт сессии с подтверждением. Критерий: звонок сам
  поднимает сессию, ручной старт не конфликтует.
- [ ] **Релиз-сборка (D7)** — release-профиль (LTO уже включён), варианты
  CPU и CUDA, инсталлятор/запуск, README с инструкцией, сборка тега
  вручную без CI/подписи. Критерий: чистая машина без Rust запускается
  после распаковки и проходит онбординг.
