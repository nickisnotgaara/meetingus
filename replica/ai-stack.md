# AI Stack — результаты спика (Фаза 1, задача T1)

Дата: 2026-11-24. Машина (min-spec reference): **i5-12400F (6C/12T), 16 GB RAM, RTX 4060 8 GB, Win 11, driver 591.74**.
Инструменты: legacy-бинарь (`--transcribe-wav`), `replica/spike/cpu-bench` (CPU-only whisper-rs), `replica/spike/mimo-test*.ps1` (streaming TTFB).
Тестовое аудио: `spike/spike-en-16k.wav` — 116.1 s, 16 kHz моно, TTS (Zira, en-US), чистая речь.

## 1. STT — whisper.cpp

### GPU (CUDA, warm; legacy-бинарь)

| Модель | Размер | Decode (116.1 s аудио) | RTFx | Качество (наблюдение) |
|---|---|---|---|---|
| tiny | 74 MB | 0.957 s | **121×** | хорошее на чистом TTS |
| base | 141 MB | 1.235 s | **94×** | почти без ошибок |
| small | 465 MB | 2.205 s | **53×** | без ошибок («14%», «3%», en p=0.999) |
| large-v3-turbo-q5_0 | 530 MB | 3.294 s | **35×** | без ошибок |

- Холодный старт (первый запуск CUDA): ~23 s (JIT-компиляция ядер) — один раз за сессию ОС; далее init ≈ 0.5 s.
- **Частичная (streaming) задержка ≈ VAD-endpoint (0.3–0.5 s) + decode чанка (чанк 1–2 s ÷ RTFx):**
  - GPU small: decode чанка 1 s ≈ 19–38 ms → **partial ≈ 0.35–0.6 s** — в пределах soft-бюджета 1.5 s ✓
  - GPU turbo: ≈ 0.36–0.57 s ✓

### CPU-only (6 threads, `cpu-bench`, GGML_NATIVE default ON)

| Модель | Decode (116.1 s) | RTFx | partial ≈ VAD + чанк 1 s | Вывод |
|---|---|---|---|---|
| base | 47.94 s | **2.4×** | ≈ 0.7–0.9 s ✓ | единственный живой вариант на CPU |
| small | 166.15 s | **0.7×** | ≈ 1.7–1.9 s ✗ | **медленнее реального времени** — не годится |
| turbo q5 | 713.38 s | **0.2×** | ✗ | в 5× медленнее реального времени |

### Выводы по STT
- **GPU (≥8 GB VRAM): дефолт small** (53× — огромный запас, точность на уровне turbo на чистой речи); turbo — запасной, если на реальной речи small покажет хуже (Фаза 4/6).
- **CPU-only: только base** (2.4×, partial ≈ 0.7–0.9 s ✓). small/turbo на CPU не поспевают за реальным временем → **wizard (D13) рекомендует по железу: GPU → small, CPU-only → base**; размеры для скачивания: base 141 MB / small 465 MB / turbo 530 MB.
- Min-spec зафиксирован: CPU-only = 6-ядерный современный (класс i5-12400F) + base; GPU = любая CUDA ≥8 GB + small.
- Deepgram вырезан (D9) — замеры подтверждают укладку в soft-бюджет 1.5 s на обоих тирах (GPU с запасом, CPU — впритык на base).
- WER замерен «на глаз» на TTS; настоящий WER на реальной речи/эхо — Фаза 4/6 (edge: колонки, акценты).

## 2. LLM — Xiaomi MiMo API (`token-plan-sgp.xiaomimimo.com/v1`, streaming, TTFB ≈ TTFT)

| Модель | Prompt | TTFT min | TTFT max | Полный ответ (≤64 tok) |
|---|---|---|---|---|
| mimo-v2.6-flash | маленький (~100 tok) | 1.70 s | 2.38 s | 2.4–3.1 s |
| mimo-v2.6-flash | большой 6.7 KB (транскрипт) | **1.06 s** | 5.43 s (холодный 1-й запрос) | 3.1–11.1 s |
| mimo-v2.6-pro | маленький | 1.42 s | 1.91 s | 2.4–2.7 s |
| mimo-v2.6-pro | большой 6.7 KB | 1.25 s | 2.50 s | 2.9–4.3 s |

- **Vision: работает** — flash принял `image_url` (data URI), вернул «Red» (`image_tokens: 9`). OCR-fallback **не нужен**; vision-контекст = mimo-v2.6-flash.
- Ответ содержит `reasoning_content` (think-токены) — фильтровать при рендере (как в legacy).
- Дисперсия TTFT по сети значительная (1.06–5.43 s); первый запрос в холодном состоянии — самый медленный.
- Prompt cache: префикс (system + история транскрипта) кэшируется → вход по кэшу почти бесплатен и, вероятно, быстрее.

### Бюджет Assist e2e — РЕАЛЬНОСТЬ И РЕШЕНИЕ (D16)
e2e = partial-транскрипт (GPU ≈ 0.4–0.6 s) + TTFT (1.1–2.5 s типично) → **типично 1.5–3 s, холодный до ~6–7 s**.
Жёсткий гейт ≤2 s из D10 типично НЕ проходил — упирается в TTFT сети, не в наш код.
**D16 (утверждён):** гейт Фазы 6 = **«первый токен ≤2.5 s типично, p95 ≤5 s»** + мгновенный UI-индикатор при Ctrl+Enter (скелетон «думаю…», perceived <300 ms). Сетевая часть документируется, не тестируется как наша.

- Оценка стоимости типичного Assist-запроса (flash, ~1K вход + 200 выход): **≈ $0.0002** (100 запросов ≈ $0.02). С кэшем — ещё дешевле. Копейки.
- Ключ: PAYG (обычный API key) **или** Token Plan ($6–100/мес, кредиты; ночью 0.8×). V2.6 — MIT-лицензия, есть и на OpenRouter по тем же ценам.
- Доступность: endpoint SG отвечает (200), streaming работает. V2.5-модели deprecated (21.10.2026) — используем v2.6 ID.
- **Бонус:** у MiMo есть свой ASR `mimo-v2.5-asr` — **$0.074/час аудио** (≈ $0.0012/мин). Не тестировался на стриминг; опция на будущее с тем же ключом (не открываем — локальный ASR укладывается).

## 4. Итоговые решения спика (к утверждению)

1. **STT дефолт:** whisper **small** на GPU (53× RTFx, partial ≈ 0.4–0.6 s ✓); размер модели в wizard: base (141 MB) / small (465 MB) / turbo (530 MB) — рекомендация small при ≥8 GB VRAM, base при CPU-only.
2. **LLM:** flash = Assist/заметки (дёшево, vision есть), pro = Smart. Оба через один ключ.
3. **Vision:** flash с image_url — скриншот-контекст штатно, OCR не нужен.
4. **Гейт Assist (D16):** первый токен ≤2.5 s типично / p95 ≤5 s + мгновенный индикатор; сетевой TTFT документируется, не гейтится.
5. **Min-spec:** CPU-only (6C) → base, partial ≤1 s; GPU ≥8 GB → small, partial ≈0.5 s.
